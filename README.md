# agent-plugins

## explaining-until-understood

질문에 맞춰 근거를 확인하고, 용어와 권고 이유를 설명하는 스킬입니다. 이해가 막히면 설명 방식을 바꾸며, 짧은 실패 이력을 함께 읽어 같은 실수를 피하도록 돕습니다.

### Claude Code

```bash
claude plugin marketplace add ai-ext/agent-plugins
claude plugin install explaining-until-understood@ai-ext
```

### Codex

```bash
codex plugin marketplace add ai-ext/agent-plugins
codex plugin add explaining-until-understood@ai-ext
```

설치 후 새 세션을 시작합니다.
